# 修仙祕笈使用說明書

適用版本為 **1.3.2 正式版（Windows 免安裝版）**。程式會尋找遊戲中的靈氣圖示；若圖示被遮住，但「×2 靈氣」字樣仍清楚可見，也能依文字位置點擊其上方。

## 啟動時自動更新

開啟程式時會檢查 GitHub 最新正式 Release。檢查、自測與啟動新版時顯示動態進度條，下載時顯示實際百分比。勾選主畫面的「自動更新軟體」後，從下次啟動起會自動安裝最新正式版。預設未勾選，若有新版可按「更新軟體」或「稍後」。新版會下載到目前 EXE 的資料夾，通過 SHA-256 驗證、自測並啟動後，自動刪除本次執行的舊 EXE。資料夾需要寫入權限。離線時會開啟目前版本。1.0.0 使用者需先手動取得目前正式版一次。

發布新版時，同步更新 cultivation_update.py 的 VERSION，以 v主版.次版.修訂 或純版本號建立正式 Release，附上 cultivation_主版.次版.修訂.exe，設為 latest。更新器使用 GitHub 提供的 SHA-256 摘要核對下載內容。

## 設定與暫存清理

舊版的 AutoUpdate 設定會移至目前使用者的 Software\CultivationSettings。確認寫入成功後移除舊值，舊機碼為空時也會刪除。更新下載暫存會於完成或失敗時清除，啟動及正常關閉時也會清理程式資料夾中本工具留下的專用暫存檔。單檔執行環境由打包器在正常結束時清理。

## 第一次使用

1. 先開啟遊戲，進入會出現靈氣的畫面。
2. 雙擊 `cultivation_1.3.2.exe`。辨識圖片已內建，執行 EXE 無須安裝 Python。
3. 展開「目標視窗」選單，選擇「搜尋雷電 ADB 裝置」。
4. 確認選單顯示的名稱及下方預覽，再按 **▶ 開始辨識**。預覽會收起，狀態列會顯示辨識狀態或點擊次數。
5. 按 **Ⅱ 暫停**即可停止辨識、恢復預覽並重新選擇目標。程式每次啟動預設為深色，取消勾選右上角的「深色模式」可切換為淺色。

## 雷電模擬器 9.1（ADB）

1. 開啟要控制的雷電實例，在模擬器設定中找到 **ADB 偵錯**，選擇**開啟本機連線**，儲存設定。若雷電提示重新啟動，請重啟該實例。
2. 回到工具，在「目標視窗」選單按「搜尋雷電 ADB 裝置」。若跳出檔案選擇視窗，請選雷電安裝目錄下的 `adb.exe`。
3. 找到一台裝置時會自動選取；有多台時，展開選單並選擇對應實例，例如 `ADB · emulator-5554`。先用預覽確認遊戲畫面。
4. 按 **▶**。狀態列中的解析度是實際擷取的裝置畫面大小，例如 `ADB 1920 × 1080`。操作途中若暫時離線，程式會等待原裝置恢復；按 **Ⅱ** 可停止等待。

## 自動升級寶劍

預設每 30 秒檢查一次。左右滾輪分別設定分鐘和秒鐘（各 0～59），最短間隔為 1 秒。可拖曳、使用滑鼠滾輪或方向鍵調整，亦可獨立關閉寶劍檢查。找到入口後會開啟介面，左側顯示「升級」就點一次，再關閉介面。找不到入口或升級介面時，繼續偵測靈氣。

## 自動渡劫（ADB 專用）

選取 ADB 裝置，開啟「自動渡劫」並按 **▶**。開關預設關閉。預設每 1 分鐘檢查，成功率高於 70% 才點擊標誌中心。可選高於 50%、60%、70%、80%、90%，或僅限 100%。檢查間隔可選 1～5 分鐘，變更間隔會重新計時。數字不清楚或找不到標誌時會跳過。點擊標誌後會檢查確認視窗最多 5 秒；辨識到視窗標題與綠色「渡劫！」按鈕後，會點一次按鈕。若商店正在升級，會在商店流程結束後檢查。

## 自動升級商店（ADB 專用）

此功能預設關閉。**開啟後，程式會實際點擊綠色升級按鈕，可能花費遊戲內資源。**

1. 選取 ADB 裝置，開啟「自動升級商店」。
2. 從旁邊的選單選擇 **1、2、3、4 或 5 分鐘**，預設為 5 分鐘。開啟開關或更改間隔時會重新計時。
3. 按 **▶** 開始辨識。到期後，程式會暫時停止靈氣點擊，尋找「商店」按鈕並開店。
4. 程式每次辨識到綠色「升級」按鈕就點一次，然後重新檢查。連續兩次沒有看到綠色升級按鈕後，會再點「商店」關店，恢復靈氣辨識並開始下一輪倒數。

若只想收集靈氣，關閉「自動升級商店」即可。若在商店操作途中看到「商店點擊結果未確認」，請先查看模擬器，手動關閉仍開著的商店，再按 **▶** 繼續。

## 常見問題

| 遇到的情況 | 處理方式 |
| --- | --- |
| 選了雷電，但沒有商店開關 | 確認選單顯示的是 `ADB · …`。若尚未選取裝置，請重新搜尋並選取對應實例。 |
| 搜尋不到 ADB 裝置 | 確認要控制的雷電實例已啟動、ADB 本機連線設定已生效，再重新搜尋。 |
| ADB 預覽較慢 | 工具會優先使用對應雷電視窗的即時縮圖；無法對應時改用 ADB 截圖。按 ▶ 後預覽會收起，仍可由狀態列確認辨識進度。 |
| 看得到靈氣卻沒點擊 | 先暫停，用預覽確認選對目標。讓青色圖示或「×2 靈氣」字樣清楚露出。 |
| 商店沒有馬上打開 | 確認已選 ADB 裝置、開啟商店開關並按 ▶。程式會等選定的分鐘數到期才開始檢查。 |
